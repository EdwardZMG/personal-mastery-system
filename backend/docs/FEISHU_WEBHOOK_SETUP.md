# 飞书双向对话 Webhook 配置指南

## 概述

本系统已实现飞书机器人双向对话功能，您可以通过飞书消息直接记录冥想、运动、阅读等数据，并查询成长进度。

**核心功能：**
- ✅ 自然语言意图识别（支持6种指令类型）
- ✅ 自动记录冥想/运动/阅读数据
- ✅ 实时查询今日成长进度
- ✅ 每日打卡功能
- ✅ 智能反馈与激励

## 飞书开放平台配置步骤

### 步骤1：创建或选择应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 使用已有应用 `cli_aa410c43d4b8dcb8` 或创建新应用
3. 进入「应用能力」→「机器人」

### 步骤2：配置事件订阅

1. 进入「事件与回调」→「事件订阅」
2. 开启「启用事件订阅」
3. **请求网址 URL：** 
   ```
   http://YOUR_SERVER_IP:8000/api/v1/feishu/webhook
   ```
   - 如果是本地开发，需要使用内网穿透工具（如 ngrok）
   - 生产环境请使用公网IP或域名

4. **加密策略：** 选择「不使用加密」（开发阶段）或「使用加密」（生产环境）

5. **订阅事件类型：** 勾选以下事件：
   - ✅ `im.message.receive_v1` - 接收消息事件
   - ✅ `im.message.group_at_msg_receive_v1` - 群聊@机器人消息（可选）

6. 点击「保存」，飞书会发送验证请求到您的服务器

### 步骤3：权限配置

确保应用拥有以下权限：

**IM相关权限：**
- `im:message` - 发送消息
- `im:message:send_as_bot` - 以机器人身份发送消息
- `im:message.p2p_msg:get_as_user` - 获取单聊消息
- `im:message.group_msg:get_as_user` - 获取群聊消息

**通讯录权限（可选）：**
- `contact:user.basic_profile:readonly` - 读取用户基本信息

### 步骤4：版本发布

1. 进入「版本管理与发布」
2. 创建新版本
3. 提交审核（如需）
4. 发布上线

### 步骤5：测试

1. 在飞书中找到您的机器人
2. 发送测试消息："帮助"
3. 确认收到回复

### 方案1：增强规则引擎

### 方案2：集成NLP模型

- 复杂指令使用NLP模型（高准确率）
-  fallback机制保证可用性

## 安全注意事项

### 1. 签名验证

生产环境**必须**启用签名验证，防止伪造请求：

```python
# 在 feishu_bot.py 中取消注释
if not verify_feishu_signature(body_bytes, signature, timestamp):
    raise HTTPException(status_code=401, detail="Invalid signature")
```

### 2. App Secret 保护

- ❌ 不要将 App Secret 提交到 Git
- ✅ 使用环境变量或密钥管理服务
- ✅ 定期轮换密钥

### 3. 速率限制

建议对 webhook 端点添加速率限制，防止滥用：

```python
from slowapi import Limiter
limiter = Limiter(key_func=get_remote_address)

@router.post("/webhook")
@limiter.limit("10/minute")
async def handle_feishu_webhook(request: Request, ...):
    ...
```

## 故障排查

### 问题1：收不到回复消息

**可能原因：**
- Webhook URL 配置错误
- 服务器未启动或端口被占用
- 防火墙阻止了请求

**解决方法：**
1. 检查后端日志：`tail -f backend/logs/app.log`
2. 测试 webhook 端点是否可达：`curl http://YOUR_IP:8000/api/v1/feishu/webhook`
3. 检查飞书开放平台的事件订阅状态

### 问题2：意图识别不准确

**可能原因：**
- 用户表达方式不在关键词列表中
- 参数提取失败

**解决方法：**
1. 查看日志中的原始消息文本
2. 在 `INTENT_PATTERNS` 中添加新的关键词
3. 优化 `extract_parameters` 函数

### 问题3：数据库写入失败

**可能原因：**
- 数据库连接断开
- 字段类型不匹配

**解决方法：**
1. 检查 PostgreSQL 服务状态
2. 查看后端异常日志
3. 验证 UserProfile 表结构
