## 激活步骤

### 第 1 步：登录飞书开放平台

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 使用您的飞书账号登录
3. 进入「开发者后台」

### 第 2 步：选择或创建应用

1. 找到应用 ID 为 `cli_aa410c43d4b8dcb8` 的应用
2. 如果没有，点击「创建企业自建应用」
   - 应用名称：Edward 成长助手
   - 应用描述：个人成长系统智能助手

### 第 3 步：配置事件订阅

1. 在应用管理页面，点击左侧菜单「事件订阅」
2. 开启「启用事件订阅」开关
3. **请求网址** 填入：
   ```
   https://edward-growth.loca.lt/api/v1/feishu/webhook
   ```
4. 点击「验证」按钮（如果提示验证失败，请确认后端服务正在运行）
5. 保存配置

### 第 4 步：添加事件权限

1. 在「事件订阅」页面下方，点击「添加事件」
2. 搜索并添加以下事件：
   - `im.message.receive_v1` - 接收消息事件
3. 保存并发布应用版本

### 第 5 步：配置应用可用性

1. 点击左侧菜单「版本管理与发布」
2. 点击「创建新版本」
3. 填写版本号（如 v1.0.0）和更新说明
4. 点击「线上审核」或直接「发布」（企业内部应用可直接发布）

### 第 6 步：添加机器人为好友

1. 打开飞书桌面端或移动端
2. 在搜索框输入应用名称「Edward 成长助手」
3. 点击进入应用聊天窗口
4. 发送消息测试

## 语音输入说明

**重要提示**：飞书机器人不支持直接的语音唤醒功能。

### 替代方案：使用飞书内置语音转文字

1. 在飞书聊天窗口，点击输入框旁边的 **麦克风图标**
2. 说出您的指令（如"冥想15分钟"）
3. 飞书会自动将语音转换为文字
4. 点击发送，机器人会收到文字消息并回复

### 为什么没有语音唤醒？

- 飞书开放平台的事件订阅仅支持文本消息
- 语音唤醒需要原生应用集成，不在开放平台能力范围内
- 使用飞书内置的语音转文字功能可以达到类似效果

## 故障排查

### 问题 1：发送消息后机器人无响应

**检查清单**：
1. 确认后端服务正在运行：访问 http://localhost:8002/health
2. 确认 localtunnel 正在运行：访问 https://edward-growth.loca.lt/health
3. 确认飞书事件订阅已启用且 URL 配置正确
4. 确认已添加 `im.message.receive_v1` 事件权限
5. 确认应用已发布

**查看日志**：
```bash
# 查看后端日志
cd backend
tail -f logs/app.log
```

### 问题 2：隧道连接断开

localtunnel 可能会因为网络问题断开。如果断开，重新执行：

```bash
lt --port 8002 --subdomain edward-growth
```

注意：每次重启 tunnel 可能需要更换 subdomain，并在飞书后台更新 webhook URL。

### 问题 3：签名验证失败

当前开发环境已禁用签名验证。生产环境需要：

1. 在飞书开放平台获取「事件订阅密钥」
2. 在 `.env` 文件中设置 `FEISHU_VERIFICATION_TOKEN=your_token`
3. 在代码中启用签名验证逻辑

## 安全注意事项

1. **不要公开 webhook URL**：当前 URL 是公开的，任何知道 URL 的人都可以发送请求
2. **生产环境必须启用签名验证**：确保请求来自飞书
3. **定期更换 subdomain**：避免长期暴露同一 URL
4. **监控异常请求**：检查日志中的可疑活动
