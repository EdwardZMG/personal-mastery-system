# Edward 成长系统 2.0 — 产品架构设计

> 科学分类 × 艾宾浩斯复习 × 游戏化成长 × 社交分享

---

## 一、产品哲学

**核心理念**：让成长像打游戏一样上瘾，但收获的是真实能力。

**设计原则**：
1. **科学驱动**：艾宾浩斯遗忘曲线 + 间隔重复 + 主动回忆
2. **游戏化激励**：XP 经验值 + 等级 + 成就 + 连胜 + 排行榜
3. **低阻力启动**：2 分钟法则，每次学习从最小单元开始
4. **社交正反馈**：成就可分享，成长可展示，形成正向循环

## 三、艾宾浩斯复习系统

### 3.1 遗忘曲线算法

```
复习间隔（基于记忆保持率）：

学习后 → 第1次复习：20 分钟后   （保持率 ~58%）
       → 第2次复习：1 小时后     （保持率 ~44%）
       → 第3次复习：9 小时后     （保持率 ~36%）
       → 第4次复习：1 天后       （保持率 ~34%）
       → 第5次复习：2 天后       （保持率 ~28%）
       → 第6次复习：6 天后       （保持率 ~25%）
       → 第7次复习：15 天后      （保持率 ~22%）
       → 第8次复习：30 天后      （保持率 ~21%）

每次成功回忆 → 间隔翻倍
每次失败回忆 → 间隔减半，重新从第1次开始
```

### 3.2 复习卡片类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 概念卡 | 核心概念解释 | "什么是第一性原理？" |
| 应用卡 | 实际应用场景 | "如何用第一性原理分析 XX 问题？" |
| 连接卡 | 跨领域关联 | "第一性原理与阳明心学的联系？" |
| 反思卡 | 自我反思 | "这个概念如何改变我的决策？" |
| 挑战卡 | 高阶应用 | "设计一个基于此原理的解决方案" |

    card_id, knowledge_id, card_type,

    ease_factor, interval_days,

class ShareRecord(Base):
    """分享记录"""
    share_id, user_id, share_type,
